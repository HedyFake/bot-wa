# 23 — API Integration Snippets (NVIDIA + OpenAI SDK)

Dokumen ini memberi pola implementasi awal. Jalankan hanya setelah API key baru dibuat dan disimpan pada secret storage.

## Client factory

```ts
import OpenAI from 'openai';

export function createNvidiaClient() {
  const apiKey = process.env.NVIDIA_API_KEY;
  if (!apiKey) throw new Error('NVIDIA_API_KEY is required');

  return new OpenAI({
    apiKey,
    baseURL: process.env.NVIDIA_BASE_URL ?? 'https://integrate.api.nvidia.com/v1',
    timeout: Number(process.env.NVIDIA_TIMEOUT_MS ?? 60_000),
    maxRetries: Number(process.env.NVIDIA_MAX_RETRIES ?? 1),
  });
}
```

## Model registry

```ts
export const MODEL_IDS = {
  ultra: 'nvidia/nemotron-3-ultra-550b-a55b',
  superVl: 'nvidia/nemotron-3.5-super-vl-120b-a12b',
  lightning: 'nvidia/nemotron-3.5-lightning-30b-a3b',
} as const;

export type ModelAlias = keyof typeof MODEL_IDS;
```

## Vision message

For Super-VL, use OpenAI-compatible multimodal message content:

```ts
const messages = [{
  role: 'user' as const,
  content: [
    { type: 'text' as const, text: 'Baca foto jadwal ini dan keluarkan data sebagai JSON.' },
    { type: 'image_url' as const, image_url: { url: signedImageUrl } },
  ],
}];
```

`signedImageUrl` must be generated by the application's protected storage layer and must expire. Do not accept arbitrary user-supplied URL as trusted content. Validate MIME, size, and URL host before request.

## Text request with auto-selected model

```ts
const alias = await modelRouter.select({
  modality: 'text',
  task: 'group_message_classification',
  complexity: 'low',
  language: 'id',
});

const completion = await nvidia.chat.completions.create({
  model: MODEL_IDS[alias],
  messages,
  temperature: 1,
  top_p: 0.95,
  max_tokens: 2048,
  stream: false,
});

const finalText = completion.choices[0]?.message?.content;
```

This snippet assumes `modelRouter` and `nvidia` are application services. It is not meant to be pasted as a standalone script without the surrounding types, policy, and validation.

## Streaming response handling

```ts
const stream = await nvidia.chat.completions.create({
  model: MODEL_IDS[alias],
  messages,
  temperature: 1,
  top_p: 0.95,
  max_tokens: 4096,
  stream: true,
});

let finalText = '';
for await (const chunk of stream) {
  const delta = chunk.choices[0]?.delta;
  // Intentionally ignore reasoning_content.
  if (typeof delta?.content === 'string') finalText += delta.content;
}

if (!finalText.trim()) throw new Error('Model returned no final text');
```

Do not send a WhatsApp message for every token. Buffer the completed final output and send once, or use a tested edit-message feature if the provider supports it.

## Function calling policy

The model may suggest tool calls, but the application decides whether the tool can run. Use a strict registry and validate arguments (e.g., Zod). Separate read-only tools from state-changing tools and outbound send tools. State changes require an authorized actor and an approval gate.

## Parameter compatibility

NVIDIA's model-specific API references can expose different controls. Configure `reasoning_effort`, `reasoning_budget`, `chat_template_kwargs`, `parallel_tool_calls`, and `response_format` per model profile only after confirming that the chosen model endpoint accepts them. Do not broadcast all fields to every model.

## Failure handling

- 401/403: stop and alert admin privately; do not repeatedly retry bad credentials.
- 429: limited exponential backoff with jitter.
- 5xx/network timeout: bounded retry then compatible fallback.
- 400/422: treat as request/schema mismatch; do not blindly retry identical request.
- Empty/invalid output: mark review-needed; never perform a write action.
