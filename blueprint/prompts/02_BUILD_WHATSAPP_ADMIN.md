# Prompt 02 — WhatsApp Private Admin Console

Gunakan bersama `docs/03_WHATSAPP_CONNECTOR.md`, `docs/04_PRIVATE_ADMIN_CONTROL.md`, dan `docs/05_SECURITY_PRIVACY.md`.

Buat pengalaman kontrol melalui private chat WhatsApp. Admin DM adalah console utama; jangan membuat web dashboard sebagai syarat. Pastikan DM-only exact JID allowlist, bootstrap secret satu kali, no static password, RBAC, command registry, menu text, natural-language commands, preview/confirm nonce, audit log, and pause switch. Grup tidak bisa menjalankan aksi admin. Uji spoof, replay, expired token, brute force, dan command dari grup.
