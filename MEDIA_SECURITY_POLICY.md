# Kebijakan pemrosesan lampiran

- Identitas mengikuti metadata WhatsApp. Konteks grup menggunakan pasangan chat dan pengirim. Lampiran sekali lihat atau sementara ditolak. Pengguna dapat meminta analisis file sendiri melalui kutipan.
- Isian file, transkrip, judul dan nama lembar merupakan data. Model analisis tidak menerima tool administrasi atau pengiriman. Parser tidak menjalankan macro, script, URL yang ditulis di dokumen, atau program dari arsip.
- ZIP membatasi jumlah entri, ukuran hasil dan rasio kompresi. XML diperiksa sebelum parsing. FFmpeg memakai argumen terpisah, demuxer yang ditentukan dari format dan protokol file/pipe. File temporer rekaman dihapus dalam blok finally.
- Masa simpan konteks adalah 30 menit. Worker membersihkan data kedaluwarsa setiap menit. FileVault mengenkripsi buffer dan hasil ekstraksi. Penghapusan konteks tidak menghapus pesan yang telah disampaikan di WhatsApp atau salinan cadangan VPS.
- Untuk materi pasien, gunakan salinan anonim sejak sebelum unggah. Pemeriksaan pola identitas pada teks dan caption tidak dapat menjamin anonimitas wajah, suara atau detail gambar. Materi dikirim ke provider saat pengguna meminta analisis yang memerlukannya.
- Hasil, log dan ringkasan tidak memberi hak baru. Dokumen LMS dan Drive mengikuti izin di modul sumbernya. HdyBot tidak memasukkan lampiran percakapan ke basis pengetahuan global secara otomatis.
